# JavaScript Basics — Exercises

Solutions for the JavaScript Basics assignment covering:

- **Part 1:** Variables & Data Types (Tasks 1–7)
- **Part 2:** Operators & Expressions (Tasks 8–14)
- **Part 3:** Conditions (Tasks 15–21)
- **Part 4:** Loops (Tasks 22–28)

## How to run

Each task is in its own `.js` file. To run any file:

```bash
node part1-variables/task01-typeof.js
```

(You need Node.js installed.)

## Folder structure

```
.
├── part1-variables/   (Tasks 1–7)
├── part2-operators/   (Tasks 8–14)
├── part3-conditions/  (Tasks 15–21)
└── part4-loops/       (Tasks 22–28)
```

## Notes

- Some tasks (like Task 1, Task 5, Task 7, Task 8, Task 9, Task 21) ask to **predict the output** — the predictions are written as comments inside the `.js` files next to each `console.log`.
- Task 7 (truthy/falsy table) is included as a comment block inside `task07-truthy-falsy.js`.
